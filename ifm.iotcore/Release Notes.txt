ifm IoTCore.NET
2023.1 Version 4.2.17
Released 2023/12/20
***************************************************************************************************
 
What's new
---------------------------------------------------------------------------------------------------
A) IoTCore
  * Cleanup namespaces.
    - Follow pattern company.product.component.
  * Support network API version 2.0.
  * Introduced microservice architecture.
    - Separated basic services and managers in IoTCore assembly into multiple assemblies.
  * Added user manager.
    - Supports simple user name and password check.
  * Added persistence manager.
    - Records all service calls with persist flag set to true and runs the service calls after restart.
  * Added element manager to manage element tree.
    - Required to avoid issues with multithreaded access to element tree.
    - Programming API change!
  * Split iotcore super class into dedicated classes for separation of concern.
    - Programming API change!
  * Support strongly typed service element classes.
  * Added read only and write only data element classes.
  * Added simple data element classes.
  * Send events in task to decouple sending events from event raised.

B) Network adapters
  * Added https server network adapter.
  * Added mqtts server network adapter.
  * Updated Visualizer to Version 2.25.225

C) Profiles
  * Added DeviceManagement profile to support ecomat, new basic and old basic controller.
  * Enhanced iodd-extender profile.
    - Create process data elements from processdatarefcollection or processdatacollection.
    - Add iodd parameter metadata information to corresponding elements.
    - Support iodd array type.
    - Support iodd enumerated integer and float values ranges as element format.
    - Added runcontrol profile to ioddextender profile.
    - Added iodd condition reader cache.

D) Code quality and documentation
  * Added doxygen documentation to iotcore sdk nuget package.
  * Added doxygen documentation for iotcore.common, iotcore.contracts and iotcore assemblies.
  * Updated iotcore integration guide.
  * Improve unit test code coverage and create unit test code coverage report.

Bug fixes
---------------------------------------------------------------------------------------------------
